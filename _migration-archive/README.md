# Migration archive

These files were the pre-WordPress custom CMS admin (page/section builder, blog editor,
media library, SEO manager, navigation manager, site content editor, inline click-to-edit
overlay). They were moved here — not deleted — when the CMS backend moved to headless
WordPress, since this repo has no git history to recover them from otherwise.

Safe to delete for good once the WordPress migration is verified working end-to-end
(see the plan's Verification section) and you're confident you won't need to reference
the old implementation.
